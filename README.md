# Everything Routes

One static page, no build step, no dependencies.

Three design routes for the Everything Network website, switchable live, with
the Framer build plan, hero imagery treatment, migration map and CMS structure
behind them.

Display type is Instrument Serif standing in for Domaine, which ships as a
licensed file at build. Hero art is generated in the browser, not client
footage. Headlines are the client's own approved copy.

## Run

```bash
npm run dev          # http://localhost:3000
```

## Deploy

```bash
vercel --prod
```

Framework preset **Other**, build command none, output directory `.`.
